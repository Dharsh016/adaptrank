One observation on the rank output — note for README: Students returning only 2 courses with the same module code (AAA, AAA or DDD, DDD) is correct OULAD behaviour. OULAD students enroll in the same module across different presentations (semesters). The ranker is ranking presentations of the same module, not different modules. This is not a bug — it accurately reflects the dataset. Worth one line in your README: "OULAD students typically enroll in 1–3 module presentations; ranking reflects presentation-level ordering."NDCG=1.0 for these students is correct — with 2 items, if the higher-scored item has higher relevance, NDCG is perfect.
